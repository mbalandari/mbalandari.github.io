TCS Analyzer

A Python tool for processing Triaxial Compressive Strength test data and generating Mohr–Coulomb envelopes.

Overview

The TCS Analyzer processes triaxial test data, computes peak strength under confinement, and generates Mohr circles and failure envelopes. It is designed for geotechnical engineers analyzing rock strength parameters.

Features

  • Peak strength detection for each confining pressure.
  • Mohr circle generation.
  • Linear Mohr–Coulomb envelope fitting.
  • Cohesion and friction angle calculation.
  • CSV input and cleaned CSV output.
  • Batch processing for multiple tests.

Tech Stack

Python Pandas Matplotlib Rock Mechanics TCS Testing
