Rock Mass Classification Tool

A desktop application for RMR, Q-System, and GSI classification with plotting and report export.

Overview

This tool implements standard rock mass classification systems (RMR, Q-System, GSI) in a unified GUI. It allows engineers to input parameters, visualize results, and export structured reports for documentation.

Features

  • RMR calculation with detailed component breakdown.
  • Q-System computation with term-by-term transparency.
  • GSI estimation based on structure and surface condition.
  • Support recommendations derived from Q categories.
  • PDF, DOCX, and TXT report export.
  • RMR bar charts and other plots embedded in reports.

Tech Stack

Python PySide6 Matplotlib Rock Mechanics RMR / Q-System / GSI
