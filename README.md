## Featured Engineering Projects

### 🪨 Rock Mass Classification Tool

**RMR · Q-System · GSI**

A Python-based engineering application for rock-mass characterization using
**RMR, Q-System, and GSI** classification methods.

The application provides engineering calculations, visualization,
support assessment, and automated reporting.

**Technologies:** Python · PySide6 · Matplotlib · ReportLab · python-docx

👉 **[View Project](https://github.com/mbalandari/rockmass-classification-tool)**

---

### 📈 Triaxial Test Analyzer

**Triaxial Testing · Mohr Circles · Mohr-Coulomb**

A Python desktop application for processing and interpreting
**triaxial rock mechanics laboratory data**.

The application processes test data, calculates engineering parameters,
generates Mohr circles and Mohr-Coulomb failure envelopes, and produces
engineering reports.

**Technologies:** Python · PySide6 · Pandas · Matplotlib

👉 **[View Project](https://github.com/mbalandari/triaxial-test-analyzer)**

---

### 🧪 UCS Analyzer

**UCS · Stress-Strain · Rock Strength**

A Python-based engineering application for automated analysis of
**uniaxial compressive strength (UCS) tests**.

The tool processes laboratory data, calculates UCS, Young's modulus,
and strain at UCS, generates stress–strain plots, and produces
automated reports.

**Technologies:** Python · PySide6 · Pandas · Matplotlib

👉 **[View Project](https://github.com/mbalandari/ucs-analyzer-gui)**
